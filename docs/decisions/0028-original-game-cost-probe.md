# 0028：原游戏渲染阶段计时与深层接管调查边界

日期：2026-11-05。状态：L0/L1/L2 与有限村庄 L3；真机与完整玩法未验证。

## 授权和目标

用户明确批准深入原游戏二进制做深层接管，调查和后续设计可以进入原游戏的帧阶段、
队列生产、资源创建/更新和提交组织，不限于 NVN API 转接层。仍保留原 AArch32
游戏逻辑；本轮只加可关闭的观测，不跳过原函数，不实现新的渲染替代路径。

输入身份、原字节、ABI、失败路径、资源完成条件和证据要求仍适用。完整成本和优化
优先级统一见 [帧成本审计](../16-frame-cost-audit.md)。

## 补丁契约

完整常量见 `config/patch-plans/game-cost.json`，实现位于 `sdk_dso.c::game_cost_patch`。

| ID | main 偏移 | 测量含义 | 校验连续范围长度 | 原始首字 |
|---|---|---|---:|---|
| 0 | `3DA8FC` | 通过虚表组织的一帧渲染阶段 | 1672 B | `e92d4ff0` |
| 1 | `BBE154` | 命令缓冲组织/提交阶段 | 1284 B | `e92d4ff0` |
| 2 | `BBE66C` | 原队列记录、结束记录及提交 | 388 B | `e92d4ff0` |
| 3 | `BC0874` | 帧尾提交/目标更新/呈现阶段 | 876 B | `e92d41f0` |

这些名称描述已观察的用途，不冒认原始类名。guard 范围是已核对的连续字节，包含
局部 literal；不声称覆盖所有共享尾部。模块身份在 loader 中先通过，再核对四处范围
SHA256 和首字；全部核对完成后才改写第一处。每处只覆盖 4 B，替换为到追加 island 的
A32 B。每处 island 20 B：8 B 绝对 veneer + 原 PUSH 和 8 B 绝对返回，共 80 B。
对齐、映像容量、每个 B 的 ±32 MiB 范围全部检查，日志记录实际基址、范围和距离。

四个入口都按 A32、r0 对象参数核对，没有栈上传入参数。wrapper 保存 r4/LR，维持
8 字节栈对齐，经已有完整 host bridge 保存/恢复 GPR、VFP、FPSCR；enter 将 r12
设置为原入口 trampoline，重放原 PUSH 后回到 `site+4`。原函数照常返回，leave 不
解释或修改它的 r0/r1/浮点返回值；r12 是 AAPCS caller-scratch，用于选择钩子和跳转。
caller LR 取自 wrapper 栈的 `SP+4`。未验证异常穿过这些 wrapper 的展开语义。

## 记账与重叠

`game-cost.enable` 默认不存在，因而不安装上述补丁。启用后 64 个 executor 槽各有
16 层有界栈。每个返回记录同进程时钟的起止、site、context、caller、线程槽、深度、
包含时间和扣掉直接子钩子后的 self。溢出、错误返回顺序、时钟倒退显式报错并失败。

第二版进一步把原函数内部通过 `dispatch_locked` 进入平台桥的墙钟计入当前最内层的
`bridge_us`；子原函数的 bridge 只归子层，不能再归父层。self 扣除 bridge 后仍然是
墙钟，含调度及未插点路径，不能叫 CPU 周期或完整游戏逻辑时间。

`analyze_game_cost.py` 对原函数区间及 ADR 0027 的 worker root journal 做区间并集：

```text
整帧墙钟 = worker 区间
         + 原函数区间中不与 worker 重叠的部分
         + 两者均未覆盖的时间
```

worker 区间之和必须与同一快照端点的 root 累计差完全相等，并且 worker 区间互不重叠，
否则分析失败。不能把原函数约一百多毫秒的包含时间，再加到后端一百多毫秒上。
逐函数均值只用完整落在窗口内的调用；区间并集会精确裁剪跨边界部分。

## 验证与未验证范围

相对基点构建，最终 loader ELF 的 text 从 676868 增至 689700 B，data 从 69192 增至
69208 B，BSS 从 4621168 增至 4672880 B，总增 64560 B；主要静态增量来自每 executor
的原函数计时栈。main 模块本轮另追加 80 B island，旧 root A/B 的 20 B 仍按原契约。
模块基址随构建布局变化，实际地址和每处 branch reach 已在各运行日志核对，不按旧基址
写绝对地址。真实内存/cache/异常展开仍待 L4。

宿主覆盖原函数/worker 重叠、边界裁剪、缺失 journal、bridge 超出 self 和资源捕获
完整性；四处真实 guard 与分支距离已在受保护运行中接受，原游戏确实执行并返回。
村庄窗口、时间范围、包身份和恢复情况统一在主报告。L3 不等于整个引擎、所有线程
CPU 时间或硬件 GPU 执行时间。任务、住宅、异常路径、长时间与 L4/L5 均未验收。
