# 0002 单一 1.4.0 输入锁

- 状态：已采纳
- 日期：2026-10-31
- 决策者：项目维护者

## 背景

不同版本/地区的模块、RomFS 和 NACP 布局不同。运行时补丁绑定模块偏移和原字节；
混入其他版本会导致难以诊断的崩溃或静默错误。

## 决定

1. `config/target-1.4.0.json` 是唯一输入锁，记录四模块 SHA256、Build ID、大小、
   NPDM/NACP 哈希和 display version。
2. 只接受完整 1.4.0（含 chS/chT 中文资源）。
3. 构建 configure 阶段校验 SDK 契约头；运行时再次核对模块身份。
4. 输入不符必须停止，不能通过改锁文件、跳过检查或“重建头”来适配。

## 后果

- 贡献者必须提供正确输入；错误版本会尽早失败。
- 更新游戏/地区需要新锁文件和新 ADR，不能静默扩展。
- 中文目录存在不等于中文验收，仍需实际界面/对话测试。

## 替代方案

- **宽松版本匹配**：会把不兼容布局当成可用，风险高。
- **运行时自动识别并适配**：需要完整的多版本契约，当前没有证据。

## 证据

- `tools/input/verify_input.py` 与 configure 校验。
- 输入身份表见 [输入身份](../reference/input-identity.md)。
