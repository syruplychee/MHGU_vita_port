# 0008 游戏数据不进入 Git

- 状态：已采纳
- 日期：2026-10-31
- 决策者：项目维护者

## 背景

本仓库面向多人协作，可能公开或跨组织共享。游戏内容、密钥、固件、存档和派生产物
受版权/许可限制，且体积巨大。

## 决定

以下内容永不进入 Git：

- 游戏 NSP/XCI/NCA/ROMFS/ExeFS 原始或解密内容
- `prod.keys`、`title.keys`、ticket、cert
- 固件、系统存档、用户存档
- VPK/SELF/VELF/GXP/SPRX 等生成二进制
- 由游戏内容派生的纹理、模型、着色器包
- 原始运行日志、截图、dump、存档备份

`.gitignore` 覆盖这些路径/扩展名；PR 审查必须检查。需要共享时使用合法的私有渠道，
并确认不违反游戏/第三方许可。

## 后果

- 仓库保持可公开审查，体积可控。
- 新贡献者必须自备游戏输入，按文档放置。
- 构建/运行需要本地准备，不能“clone 即玩”。

## 替代方案

- **提交生成物方便复现**：法律与体积风险不可接受。
- **Git LFS 存游戏数据**：仍然涉及版权/许可，不可取。
