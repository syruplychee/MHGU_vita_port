# 0001 保留原始 AArch32 游戏逻辑

- 状态：已采纳
- 日期：2026-10-31
- 决策者：项目维护者

## 背景

MHGU 的游戏逻辑、AI、任务、战斗、动画和存档语义都在原始 AArch32 模块中。重写游戏
或使用解释器/JIT 会带来巨大的工作量、语义偏差和性能风险，也无法复用已有验证。

## 决定

1. 保留 `rtld/main/subsdk0/sdk` 原始代码，在 Vita CPU 上原生执行。
2. 只替换平台接口：文件、存档、线程、TLS、时间、输入、音频、视频、图形。
3. 不兼容指令通过离线定位和预编译 ARMv7 helper/岛处理。
4. 不允许在运行时解码并翻译任意 guest 指令。
5. 不采用整程序静态重编译、JIT、动态二进制翻译或通用 Maxwell 命令模拟器作为默认
   后端。

## 后果

- 游戏行为与原始实现保持一致，性能主要取决于平台接口效率。
- 需要精确处理 ARM/Thumb、ABI、TLS、cache、重定位和异常展开。
- 每个补丁必须绑定模块身份和原字节，输入变化时拒绝而非猜测。

## 替代方案

- **重写游戏**：工作量与法律风险不可接受。
- **解释器/JIT**：Vita CPU/内存预算不足，且偏离“保留原逻辑”。
- **整程序静态重编译**：无法覆盖动态代码、异常和平台边界。

## 证据

- 四模块解码/重定位/局部执行：L3（Vita3K）。
- 真机映射与 cache：未验证，见 [真机](../07-hardware.md)。
